# mts_ml_comp_2
## Решение задачи по предсказанию дней занятости (или простоя) аренды недвижимости в рамках курса Школы Аналитиков Данных МТС

Для решения задачи был организовон ансамбль из семи моделей, обученных по принципу Stratify K-Fold. 
Ответ формуриется двумя способами:
- Среднее арифметическое ответов моделей
- Медиана ответов моделей

В ноутбуке содержится:
- EDA
- Подбор гиперпараметров
- Feature selection при помощи алгоритма Backward Selection
- Организация ансамбля
